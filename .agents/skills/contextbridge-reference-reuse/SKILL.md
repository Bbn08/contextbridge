Treat `../second-brain` and `../effimiser` as read-only. Check git status before and after inspection. Classify each idea REUSE, ADAPT, LEARN or IGNORE in `docs/provenance.md`. Prefer clean-room reimplementation. Never copy code, comments, tests or fixtures without explicit license/provenance recording and required NOTICE text.
